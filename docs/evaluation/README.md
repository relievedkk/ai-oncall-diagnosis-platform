| --- | --- | --- |
| 无凭据运行演示 | [重放与对照](../replay-and-comparison.md) | 合成脚本重放，检查流程和契约 |

线上诊断仍使用 Plan–Execute–Replan；single-pass 评测不等同于线上 API 的准确率。分别报告候选召回、模型提议与严格确诊，失败和拒答保留在全量分母中。

旧 V3/V4、初版 V5 和证据修复过程的结果放在[历史归档](../archive/evaluation/README.md)。读取历史结果前先检查协议、数据集暴露状态、是否调用真实模型及验证范围。

源码仓库提供合成回归案例，不附带本地 RCAEval 原始数据、留出答案或请求数据库。准备分组留出需要本地上游索引和历史暴露登记；文档中的 `.runtime/` 路径是操作示例，不表示这些材料已随仓库提供。
